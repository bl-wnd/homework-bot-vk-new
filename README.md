# Бот-ассистент проверки домашних заданий (VK)

Скрипт-бот для социальной сети ВКонтакте, который в реальном времени отслеживает статус проверки ваших домашних работ на сервисе **Яндекс Практикум** и присылает уведомления в личные сообщения.

## Основной функционал
* Опрашивает API Практикума с заданной периодичностью (раз в 10 минут).
* Анализирует изменения статуса домашней работы (взята в ревью, проверена, принята или возвращена с замечаниями).
* Отправляет детальные сообщения со статусом в ваш VK-чат.
* Защищен от дублирования сообщений и спама логами при перебоях с сетью или сервером.
* Логирует всю работу программы (уровни DEBUG, INFO, ERROR, CRITICAL) в стандартный поток вывода.

## Технологический стек
* Python 3.14.3
* `vk_api` — библиотека для удобного взаимодействия с VK API
* `requests` — для отправки HTTP-запросов к API Практикума
* `python-dotenv` — для безопасного управления секретными ключами

## Как запустить проект локально

1. **Клонируйте репозиторий на свой компьютер:**
   ```bash
   git clone https://github.com/bl-wnd/homework-bot-vk-new.git
   cd homework-bot-vk-new
   ```

2. **Cоздайте и активируйте виртуальное окружение:**
   * Для Linux/macOS:
     ```bash
     python3 -m venv venv
     source venv/bin/activate
     ```
   * Для Windows:
     ```bash
     python -m venv venv
     source venv/Scripts/activate
     ```

3. **Установите необходимые зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройте переменные окружения:**
   В корневой директории проекта создайте файл `.env` и заполните его вашими токенами (не забудьте добавить `.env` в файл `.gitignore`):
   ```env
   PRACTICUM_TOKEN=ваш_токен_практикума
   VK_TOKEN=токен_вашего_сообщества_вк
   VK_USER_ID=ваш_id_вконтакте
   ```

5. **Запустите бота:**
   ```bash
   python homework.py
   ```
